# skywalk

Программа для Windows для KZ в Counter-Strike 2. Учебный проект на Python.

**Скачать:** справа на этой странице, раздел **Releases**, файл `Skywalk.exe` в последней версии. Устанавливать ничего не нужно, просто запусти.

## Что умеет

- **Нуллы (SOCD)** для A/D и W/S: при нажатии противоположной клавиши работает последняя нажатая.
- **Бинды:** «-w» на клавишу, колесо или mouse 4/5; «66 с -w» и «66 без -w» (crouch jump); jumpbug; danvari. Клавиши прыжка и приседа программа сама берёт из настроек CS2.
- **Рекорды прыжков** (LJ, BH, MBH, WJ, LAJ и др.) из консоли CS2: лучшие за всё время и статистика сессии по тирам.
- **Тренер:** разбор прыжка по стрейфам (sync, gain, bad angles, dead air, мышь, тайминг клавиш) и советы, что исправить.
- **Прогресс:** график лучшего прыжка по дням.
- **Слежка за картами** на KZ-серверах Cybershoke: уведомление, когда нужная карта появилась на сервере в выбранных регионах; тиры карт.
- **Оверлей** поверх CS2, работа из трея, режим экономии ресурсов.

## Как включить рекорды и тренер

Программа читает консоль CS2, поэтому в Steam нужно добавить параметр запуска:
Steam → CS2 → Свойства → Параметры запуска → `-condebug`

Память игры программа не читает и в игру ничего не встраивает.

## Важно

Бинды нажимают клавиши за тебя. На некоторых серверах (в том числе в общих правилах Cybershoke) макросы запрещены. Проверь правила сервера: ответственность за использование биндов на тебе.

## Собрать самому

Нужен Python 3. В папке проекта запусти `build.bat`: он поставит библиотеки (customtkinter, pynput, pillow, pystray, pyinstaller) и соберёт `dist\Skywalk.exe`.
